# Model Artifacts

This directory contains the trained machine learning model used by the JobShield AI Streamlit application.

## Final Model

The application uses the combined Logistic Regression model:

`combined_model.joblib`

The model combines textual and structured job posting features.

## Reproducing the Model

The model can be generated by running:

`notebooks/12_save_model.py`

Reproducing the model requires downloading the original dataset from Kaggle and completing the documented data preparation and training workflow.

## Application Dependency

The Streamlit application expects the model at:

`models/combined_model.joblib`

The trained model is included in this repository so the application can be launched without repeating the training process.
