# Model Artifacts

This directory stores trained machine learning model artifacts used by the JobShield AI application.

## Final Model

The Streamlit application uses the combined Logistic Regression model:

`combined_model.joblib`

The model is generated by running:

`notebooks/12_save_model.py`

## Reproducibility

Model artifacts are excluded from Git through `.gitignore` to avoid committing large binary files.

To reproduce the model, follow the data preparation and training workflow documented in the main project README.

## Application Dependency

The application expects the trained model at:

`models/combined_model.joblib`

Make sure the model file exists locally before launching the Streamlit application.
