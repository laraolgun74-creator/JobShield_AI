# Notebooks and Experiments

This directory contains the project's data inspection, preprocessing, model training, evaluation, and demo preparation scripts.

| File | Description |
|---|---|
| `01_data_inspection.py` | Initial dataset inspection and data quality analysis |
| `02_split_check.py` | Train-test split validation |
| `03_stratified_group_split_check.py` | Stratified group split validation |
| `04_prepare_model_data.py` | Data preparation for model training |
| `05_train_baseline_model.py` | Baseline Logistic Regression model |
| `06_train_svm_model.py` | Linear SVM model |
| `07_inspect_structured_features.py` | Inspection of structured features |
| `08_train_combined_model.py` | Combined text and structured feature model |
| `09_train_text_only_model.py` | Text-only model |
| `10_compare_models.py` | Comparison of baseline models |
| `11_error_analysis.py` | Model error analysis |
| `12_save_model.py` | Saving the final model |
| `13_compare_advanced_models.py` | Random Forest and XGBoost experiments |
| `14_create_final_comparison.py` | Final model comparison |
| `15_create_final_visualization.py` | Final performance visualization |
| `16_prepare_demo_examples.py` | Preparation of presentation demo examples |

All experiments use the project dataset and evaluation methodology documented in the main README.
