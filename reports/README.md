# Reports and Results

This directory contains the evaluation results, model comparison tables, and project progress records generated during the JobShield AI experiments.

## Files

| File | Description |
|---|---|
| `model_comparison.csv` | Comparison of the initial baseline models |
| `advanced_model_comparison.csv` | Performance comparison of advanced models |
| `advanced_model_cv_results.csv` | Cross-validation results for advanced models |
| `final_model_comparison.csv` | Consolidated final model performance comparison |
| `error_analysis.csv` | Examples of model prediction errors |
| `progress_log.md` | Project development notes and progress records |

## Figures

The `figures/` directory contains visualizations generated for model evaluation and presentation purposes.

Model performance should be interpreted using precision, recall, and F1-score, considering the class imbalance in the dataset.
