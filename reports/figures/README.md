# Figures and Visualizations

This directory stores charts and visual materials generated during the JobShield AI project.

## Purpose

The figures support model evaluation, result interpretation, and project presentation.

## Guidelines

- Use clear titles and axis labels.
- Keep visualizations consistent with the metrics reported in the project.
- Make sure charts accurately represent the underlying evaluation results.
- Do not interpret model predictions as definitive proof of fraudulent activity.

The final model comparison and evaluation results are documented in the `../` reports directory and the main project README.
